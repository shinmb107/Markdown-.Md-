##### 컴파일 (코드 검사)
Ctrl + Shift + B

##### 디버깅 시작 (오류 검사 후 실행)
F5

##### 디버깅 없이 시작 (빠른 실행)
Ctrl + F5

--------------------------------------------------------------

***Ctrl 누르고 연속 입력***

##### 줄 정리
Ctrl + K -> D

##### 줄 삭제
Ctrl + L

##### 줄 주석
해당 줄에 커서 위치 후 Ctrl + /

##### 전체 주석
Ctrl + A -> /

##### 이름 일괄 변경
Ctrl + R -> R

##### 자동 완성
두 글자 입력 후 Ctrl + Space ---> tab 키로 선택
